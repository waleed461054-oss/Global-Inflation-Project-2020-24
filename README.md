## 📌 Project Overview
This project analyzes global inflation trends from 2020 to 2024 using 
Machine Learning. It predicts inflation with ~77% accuracy using XGBoost 
and Ridge Regression, and visualizes geospatial inflation patterns 
through an interactive world map.

---

## 🛠️ Tech Stack
| Tool | Purpose |
|------|---------|
| Python 3.12 | Core language |
| XGBoost | Inflation prediction model |
| Ridge Regression | Baseline ML model |
| Plotly | Interactive visualizations |
| Pandas / NumPy | Data manipulation |
| Scikit-learn | Feature engineering |

---

## 📊 Key Results
- ✅ Inflation predicted with **~77% accuracy**
- ✅ XGBoost outperformed Ridge Regression
- ✅ Interactive geospatial heatmap of global inflation
- ✅ Time series decomposition across 180+ countries

## 🚀 How to Run
1. Clone the repository
2. Install dependencies:
   pip install pandas numpy scikit-learn xgboost plotly
3. Open the notebook:
   jupyter notebook source/run_analysis.ipynb

---

## 🔍 Research Insight
This project explores the **AI Productivity Paradox** — while ML can 
predict inflation with high accuracy, real-world GDP impact is delayed 
by physical constraints like global supply chains.
